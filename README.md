# SimpleFiler

SimpleFilerは、Windows 10/11 x64向けのシンプルで軽快な2ペインファイラーです。
純Win32 UIで動作し、ディレクトリツリーや常駐サービスを持ちません。

## 主な機能

- 独立して移動できる1/2ペイン表示
- クリック可能なパンくずアドレス、直接入力、ドライブ一覧
  （戻る、進む、上へ、更新はキーボード操作）
- コピー、移動、貼り付け、ごみ箱／完全削除、名前変更、新規フォルダー
- フォルダーブックマーク、ファイルリンク、引数付きアプリリンク
- `ff...`による登録フォルダー候補と高速ジャンプ
- `aa...`による登録アプリ候補と起動
- ファイル名の再帰検索と検索中止
- Unicode／ZIP64対応のZIP作成・展開
- 現在のフォルダーでCMDまたはPowerShellを通常／管理者権限で起動
- EXE横の`simplefiler.json`へ設定を保存

## 画面イメージ

実際の画面は、次のようなシンプルな2ペイン構成です。

```text
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│ SimpleFiler                                                                              │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│ [PC] [1｜2] [登録] [★追加] [リンク＋] [端末] [ff / aa / cmd] [実行]                    │
├──────────────────┬──────────────────────────────────┬────────────────────────────────────┤
│ 登録サイドバー   │ PC › C: › Users › Documents      │ PC › D: › Work                     │
├──────────────────┼──────────────────────────────────┼────────────────────────────────────┤
│ ★ Documents      │ 名前                 サイズ  日時 │ 名前                  サイズ  日時 │
│ ★ Downloads      │──────────────────────────────────│────────────────────────────────────│
│ ★ Pictures       │ 📁 Projects   Folder             │ 📁 Releases    Folder              │
│                  │ 📁 Photos     Folder             │ 📁 Sources     Folder              │
│ ↗ memo.txt       │ 📄 memo.txt   TXT     12 KB      │ 📦 build.zip   ZIP     8.4 MB      │
│ ↗ Editor         │ 📄 report.pdf PDF     850 KB     │ ⚙ Simple.exe   EXE     2.5 MB      │
│ ↗ Terminal       │ 📷 image.png  PNG     1.2 MB     │ 📄 README.md   MD      6 KB        │
│                  │                                  │                                    │
│                  │       左ペイン（アクティブ）     │              右ペイン              │
├──────────────────┴──────────────────────────────────┴────────────────────────────────────┤
│ 5 項目                                                         左ペイン                  │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

- 「登録」ボタンで左側のブックマーク／リンク欄を折りたためます。
- 「1｜2」ボタンで1ペインと2ペインを切り替えられます。
- 中央の境界をドラッグして左右の表示幅を変更できます。
- アドレスの各階層をクリックすると、そのフォルダーへ直接移動できます。
  `Ctrl+L`またはアドレスの空白部分をクリックすると、パスを直接入力できます。
- 「端末」から、現在のペインを起点にCMDまたはPowerShellを起動できます。
- 「リンク＋」の「フォルダーリンクを追加」から、現在開いていないフォルダーも
  サイドバーに登録できます。「★追加」は現在開いているフォルダーのみ登録します。
- クイックアクセスの項目は、1回クリックするだけで開けます。

## ビルド

必要なもの:

- Windows 10/11 x64
- Visual Studio 2022（Desktop development with C++）
- CMake 3.24以降
- Git
- 初回構成時のみ、minizip-ngとzlib-ngを取得するためのインターネット接続

Developer PowerShell for VS 2022で次を実行します。

```powershell
cmake --preset windows-x64
cmake --build --preset windows-x64
ctest --preset windows-x64
```

実行ファイルは`build/windows-x64/Release/SimpleFiler.exe`です。MSVCランタイムと
ZIPライブラリは静的リンクされるため、実行時に追加のDLLやインストールは不要です。

## 使い方

`SimpleFiler.exe`を起動するか、最初に開くパスを引数で指定します。

```powershell
SimpleFiler.exe "D:\Work"
SimpleFiler.exe "D:\Work\memo.txt"
```

ファイル一覧や登録サイドバーで`ff`／`aa`（または`cmd`）まで入力すると、
上部の入力欄へ自動的にフォーカスします。先頭の`f`／`a`だけではフォーカスを
移さないため、通常の文字ジャンプにも使用できます。
ファイル一覧では文字列を入力すると、大文字・小文字を区別せず、その文字列で
始まるファイルまたはフォルダーへ選択とフォーカスが移動します。

```text
ffwork      登録フォルダーを絞り込んで移動
aaeditor    登録アプリを絞り込んで起動
cmd         現在のフォルダーでCMDを起動
cmd admin   管理者CMDを起動
```

`ff`／`aa`の登録には表示名、エイリアス、検索キーワードを設定できます。
候補は`↑`／`↓`で選び、`Enter`で実行、`Ctrl+N`で新規登録、
`Escape`で閉じます。
ファイルやフォルダーを右クリックすると、Windows標準のコンテキストメニューを
表示します。
`ff`では`Shift+Enter`で反対ペインを開きます。`aa`では
`Ctrl+Enter`で管理者起動、`Shift+Enter`で選択ファイルを渡さずに起動します。
アプリ引数には`{file}`、`{files}`、`{folder}`、`{left}`、`{right}`、
`{other}`を使用できます。

上部の「端末」から、アクティブペインのフォルダーを起点に次を起動できます。

- CMD
- 管理者権限のCMD
- PowerShell
- 管理者権限のPowerShell

PowerShell 7の標準インストール先が見つかれば`pwsh.exe`を使用し、それ以外は
Windows PowerShell 5.1へフォールバックします。管理者版だけUACが表示されます。

## キーボード

| 操作 | キー |
| --- | --- |
| コピー／切り取り／貼り付け | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| 反対ペインへコピー／移動 | `F5` / `F6` |
| 新しいフォルダー | `Ctrl+N` / `F7` |
| 名前変更 | `F2` |
| ごみ箱へ削除／完全削除 | `Delete` / `Shift+Delete` |
| 更新 | `Ctrl+R` |
| アドレスバー | `Ctrl+L` |
| 検索 | `Ctrl+F` |
| ペイン切り替え | `Tab` |
| 戻る／進む／上へ | `Alt+←` / `Alt+→` / `Alt+↑`または`Backspace` |

ファイル操作のショートカットは、ファイル一覧にフォーカスがある場合だけ有効です。
アドレスやコマンド入力中の`Delete`、`Ctrl+C`などは文字編集として動作します。
コピー、移動、削除、名前変更、フォルダー作成、ZIP処理の実行中に終了しようとすると、
確認を表示します。終了を選んだ場合も、処理スレッドを所有したまま完了まで待機します。

## 設定とポータブル利用

ブックマーク、エイリアス、キーワード、アプリリンク、ウィンドウ位置、
ペイン状態は、EXEと同じフォルダーの
`simplefiler.json`に保存されます。フォルダーごとコピーすれば設定も持ち運べます。
書き込みできない場所から起動した場合、ファイル閲覧と操作は継続できますが、
設定変更は保存されません。

## 更新方法

SimpleFilerは自動更新機能を持たないポータブルアプリです。新しいバージョンの
`SimpleFiler.exe`で置き換える前に、起動中のSimpleFilerをすべて終了してください。
実行中のまま上書きしようとすると、Windowsがexeファイルをロックしているため
置き換えに失敗します。

1. すべてのSimpleFilerウィンドウを閉じる
2. 新しい`SimpleFiler.exe`を配布ZIPから取り出し、既存の`SimpleFiler.exe`を置き換える
   （`simplefiler.json`はそのままで問題ありません）
3. 新しい`SimpleFiler.exe`を起動する

## テストと配布ZIP

自動テストにはコマンド解析、設定、アプリ引数、ポータブルパス、
実ファイル操作、CMDの特殊文字パス、1万項目の列挙、UI操作が含まれます。

```powershell
ctest --preset windows-x64
cmake --build build/windows-x64 --config Release --target PACKAGE
```

配布物は`build/windows-x64/SimpleFiler-0.0.11-windows-x64.zip`に生成されます。
ZIPには初期設定ファイルを含めず、初回の正常終了時にEXEの隣へ作成します。

## 初版で含まないもの

タブ、プレビュー、クラウド同期、FTP、ファイル内容検索、暗号化ZIP、プラグイン、
自動更新は対象外です。
