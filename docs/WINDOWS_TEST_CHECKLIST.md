# Windows実機テストチェックリスト

リリース候補はWindows 10 x64とWindows 11 x64の両方で確認します。

## 起動・レイアウト

- [ ] EXE単体で起動し、2ペインと登録サイドバーが表示される
- [ ] 1/2ペイン切り替え、分割位置、ウィンドウ状態が再起動後に復元される
- [ ] ファイル／フォルダーをコマンドライン引数に渡して開ける
- [ ] 1万項目のフォルダーでUIを操作し続けられる

## ファイル操作

- [ ] コピー、切り取り、貼り付け、同名競合、キャンセルが動作する
- [ ] 名前変更、新規フォルダー、ごみ箱削除、完全削除が動作する
- [ ] 保護領域の操作だけでUACが表示される
- [ ] Unicode、長いパス、UNC、切断ドライブ、アクセス拒否を処理できる

## 登録・検索・ZIP

- [ ] ブックマークとファイルリンクを追加、起動、削除できる
- [ ] 引数／作業フォルダー付きアプリリンクを通常／管理者権限で起動できる
- [ ] 名前検索が逐次表示され、別の移動または検索でキャンセルされる
- [ ] 検索がジャンクションを再帰せず循環しない
- [ ] Unicode名、空フォルダー、大容量ファイルを含むZIPを作成・展開できる
- [ ] `../`、絶対パス、シンボリックリンクを含む不正ZIPを拒否する

## ターミナル

- [ ] ローカルパスでCMD／PowerShellが現在のフォルダーから起動する
- [ ] UNCパスでCMDが`pushd`、PowerShellが`Set-Location`により起動する
- [ ] 空白、日本語、`&`、`^`、`%`、引用符を含むパスで起動する
- [ ] PowerShell 7の検出とWindows PowerShell 5.1へのフォールバックが動作する
- [ ] 管理者版だけUACが表示され、キャンセル時もアプリを継続できる
